# 像素空档接龙 FREECELL

一个单文件、零依赖的像素风空档接龙（FreeCell）游戏。

**在线试玩：** https://slatinwine.github.io/freecell-pixel/

## 玩法

- 点击选牌 → 点击目标放置；双击自动送上基础堆；ESC 取消选择
- 红黑交替叠放，借助 4 个自由单元腾挪，把 4 种花色各从 A 排到 K 即获胜
- 超长序列可整体搬移，上限为 `(空自由单元+1) × 2^空列` 张

## 特性

- 🕹 完整 FreeCell 规则 + CRT 扫描线 / 硬阴影像素风
- ↩️ 无限撤销 · 💡 提示 · 🔢 局号种子可复现重玩
- 💾 localStorage 自动存档，刷新续局
- 🔊 WebAudio 8-bit 音效，可开关
- 🎉 经典纸牌通关弹跳动画

纯 HTML/CSS/JS 单文件，无任何构建与外部依赖，直接打开即玩。
